# Quest Quick Start

A setting pack that supplies each Quest role's six quick-start abilities from the Quest Creators
Resource, so Quest and Cadmium characters can be created with installed materials. It adds no
creatures or maps; campaigns use it beside their adventure's settings.

| Role | Abilities |
|---|---|
| Fighter | Counterattack, Wild Attack, Provoke, Intercept, Summon the Blood, Size Up |
| Invoker | Declare, Petition, Soul Gaze, Fiery Avenger, Thunderous Word, Shield |
| Ranger | Commune, Read the Winds, Speak with Animal, Animal Partner, Track, Remedy |
| Naturalist | Animal Form, Thorn, Freeze, Cloudcall, Wild Aspect, Command Nature |
| Doctor | Mend, Sleep, Deathsense, Corrupt, Modulate, Examine the Dead |
| Spy | Cosmopolitan, Sneak Attack, Strap, Tracker, Persona, Feather Hook |
| Magician | Magic Tricks, Splitting Image, Magic Eye, Little Bird, Bamboozle, Scintillate |
| Wizard | Magic Strike, Blink, Sense Magic, Speak, Pinch, Familiar |

## Mechanics

The Creators Resource gives one line per ability; the Game Book's full text is not used. In
Cadmium every ability spends its AP and is narrated. Abilities whose line describes harm
(Counterattack, Wild Attack, Thunderous Word, Thorn, Freeze, Corrupt, Sneak Attack, Scintillate,
Magic Strike) roll and deal Quest's standard damage of 2 on a success. Mend restores 2 HP. Sleep
makes its target asleep for 3 rounds. Every other ability has no mechanical effect; the Guide's
role passes to the narrator.

Abilities with several activation costs (such as Read the Winds, 0/2 AP) use the lowest, because
an ability in the Quest system schema has one cost. The Creators Resource lists no cost for
Thorn or Tracker; both cost 0.

## Descriptions

`descriptions.yaml` holds each ability's short description from the Creators Resource, keyed by ability.
Packs have no description field, so the file sits beside the pack; the character creation form and the
character page show it under the ability, with what the ability's data does.
